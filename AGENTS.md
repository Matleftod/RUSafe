# AGENTS.md

## Objectif du projet
Ce projet est une maquette HTML/CSS/JS destinée à évoluer vers le site final.
Le rendu doit rester cohérent visuellement d'une page à l'autre.

## Règles générales
- Faire des changements minimaux et lisibles
- Ne pas casser le rendu existant sans le signaler
- Toujours privilégier la cohérence avec le style déjà en place
- Ne pas introduire de framework
- Ne pas ajouter de dépendance sans justification explicite

## HTML
- Utiliser un HTML sémantique
- Garder une structure claire par section
- Réduire les wrappers inutiles
- Respecter l'accessibilité de base (alt, labels, hiérarchie de titres, boutons/liens corrects)

## CSS
- Préférer des variables CSS pour couleurs, espaces, rayons, largeurs et transitions
- Réutiliser les patterns existants avant d'en créer de nouveaux
- Garder une architecture CSS scalable
- Éviter les styles trop spécifiques ou difficiles à surcharger
- Maintenir une logique responsive simple et cohérente

## JS
- JS minimal, lisible et découplé
- Pas de logique globale inutile
- Préférer de petites fonctions explicites
- Ne manipuler le DOM que lorsque c'est nécessaire

## Pour toute nouvelle section
- Respecter les tokens visuels existants
- Réutiliser les composants et patterns actuels
- Justifier rapidement la place de la section dans la page
- Garder le code factorisable pour les futures pages

## À la fin de chaque tâche
- Résumer ce qui a changé
- Lister les fichiers modifiés
- Signaler les points à valider visuellement
